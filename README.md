# Zıp Zıp Dünya 🌍🏃

4-9 yaş arası çocuklar için **reklamsız, şiddetsiz** bir hareket oyunu.
Sevimli maskot Zıpzıp çocukla birlikte dünyanın harikalarını gezer; her durakta
zıplama, çömelme, denge gibi hareketler ister. Macera Türkiye'den
(Efes – Artemis Tapınağı) başlar.

## Oyunu oynamak

Yayındaki sürüm: **https://8y9khd2gr8-svg.github.io/first/**

Telefonda bu linki açman yeterli.

## Değişmez kurallar

- Reklam yok
- Şiddet yok, kaybetmek yok
- Hesap/kayıt yok, çocuktan hiçbir veri toplanmaz

## Geliştiriciler için

```bash
npm install      # bir kere: gerekli parçaları indirir
npm run dev      # oyunu bilgisayarda açar (adres ekranda yazar)
npm run build    # yayına hazır sürümü dist/ klasörüne üretir
```

Kullanılanlar: [Phaser 3](https://phaser.io/) oyun motoru, TypeScript, Vite.
`main` dalına gelen her değişiklik GitHub Actions ile otomatik yayınlanır.
